# GNN 图神经网络选股框架（吸收 skill-dl-gnn-stock-graph）

> 深度图神经网络选股系统。核心增量是**图结构维度**——XGBoost 树模型无法捕捉"股票间联动关系"，GNN 的多层异构图 + 关系特征补上这一维。

---

## 一、多层异构图（关系建模）

| 边类型 | 构建方式 | 含义 |
|---|---|---|
| 申万 L1/L2/L3 行业边 | 同行业成分 | 行业联动（L3 权重 > L2 > L1，越细越强） |
| 概念板块边 | 同概念成分 | 题材轮动 |
| 机构持仓边 | 共同持仓 | 抱团 |
| **DTW 形态边** | 收益率序列 DTW 相似 Top-K | 形态相似（龙头→跟风） |
| **Pearson 相关性边** | \|corr\| ≥ 0.5 | 收益联动 |

**显性边**（行业/概念/机构）= 静态；**隐性边**（DTW/相关性/格兰杰）= 数据驱动每日重建。

---

## 二、关系特征（4 维，scripts/relation_features.py）

| 特征 | 计算 | 含义 |
|---|---|---|
| degree_centrality | 归一化度数 | 联动密度 |
| pagerank | PageRank 中心性 | 图节点重要性（龙头） |
| dtw_similarity_mean | 平均 DTW 形态相似度 | 形态同步度 |
| industry_excess_ret | 同行业平均超额收益 | 行业 beta |

**核心算法**：
- **DTW**：O(T²) 动态规划 + Sakoe-Chiba band 10% 加速；距离→相似度 [0,1]
- **PageRank**：纯 numpy 迭代 `M.T @ out + (1-alpha)/N`

## 五、与 a-share-market-analysis 的融合

| 本项目 | 融合到已有体系 |
|---|---|
| **DTW 形态相似度** | `relation_features.py`——找形态相似股（龙头涨停→跟风） |
| **关系特征（4维）** | 作为 XGBoost 新特征维度（树模型无法捕捉图结构） |
| **多层异构图** | 补充 sector_heat 的行业联动，更细（L3 + 概念 + 机构持仓） |
| **混频建模** | 日频量价 + 季频基本面 MIDAS 对齐（用户缺混频处理） |

**核心增量**：`relation_features.py`（DTW 相似度 + PageRank + 中心性，纯 numpy）。**形态相似度**是短线选股的重要维度——龙头股涨停后，找形态相似的跟风股，这是 XGBoost 单票打分做不到的"关系"信号。

**局限**：GNN 需要 PyTorch + GPU 训练（重），用户 skill 是纯函数 CPU 扫描。故只吸收"关系特征"（纯计算，可加进 XGBoost 特征），不引入 GNN 训练。
