# 性价比分析框架 — 双维度10分制

用户自定义的股票性价比评估方法，融合基本面质量与产业热点。

## 维度一：财务面（估值+安全边际+盈利能力+增长）

| 指标 | 权重 | 评估标准 |
|------|------|---------|
| PE估值 | 高 | <15x=优, 15-30x=中, >50x=高估 |
| ROE | 高 | >20%=优, 10-20%=中, <10%=弱 |
| 营收/利润增长 | 高 | >30%=爆发, 10-30%=稳增, <10%=低增 |
| 毛利率 | 中 | >50%=强护城河, 30-50%=中, <30%=竞争激烈 |
| 现金流 | 中 | 经营现金流>净利润=优质 |
| 负债率 | 低 | <40%=安全, >60%=风险 |

## 维度二：产业热点面（AI/算力、资源、机器人等）

| 主线 | 热度 | 核心标的 |
|------|------|---------|
| AI算力(光模块/服务器) | 🔥🔥🔥 | 天孚/中科曙光/华勤 |
| 铜资源 | 🔥🔥 | 江西铜业/铜陵有色 |
| 机器人/物理AI | 🔥🔥🔥 | 汇川/三花/拓普 |
| 贵金属 | 🔥🔥 | 山金国际/紫金矿业 |
| 军工 | 🔥 | 航发动力 |

## 评分规则

- 满分10分，财务和产业热点各占5分
- **成长顶级但高估（YTD>100%）**: 上限8分（安全边际扣分）
- **低估值周期股+产业共振**: 上限8.5分
- **R:R<1**: 自动降1分
- **阿娇否决（年涨>100%非三买）**: 自动降2分+标记⚠️

## 修正规则（与缠论/资金面交叉）

当分析师的性价比评分与缠论+资金面数据冲突时：

| 冲突类型 | 处理 |
|---------|------|
| 分析师高分(≥8) + 阿娇否决 | **降2分+⚠️** (如天孚通信8.5→6.0) |
| 分析师低分 + 资金共振+中枢内买 | **升1分** (如山金国际未提→7.5) |
| 分析师高分 + RR<1 | **降1分** (如中科曙光8.2→7.0) |
