# Qlib Alpha158 因子库

> **来源**: Microsoft Qlib — `qlib.contrib.data.handler.Alpha158`
> **因子总数**: 158个（9 Kbar + 4 Price + 145 Rolling）
> **数据字段**: `$open`, `$high`, `$low`, `$close`, `$volume`, `$vwap`
> **表达式语法**: Qlib Expression Engine DSL

---

## 一、Kbar 因子（9个） — 市场微观结构

K线形态因子，捕捉单根K线内的价格结构信息。无窗口参数。

### KMID
- **分类**: 微观结构
- **表达式**: `($close - $open) / $open`
- **说明**: K线中位偏移率。正值表示收阳线，负值表示收阴线，幅度反映多空力量对比。
- **使用建议**: 短期多空情绪指标，适合与成交量因子组合判断趋势可靠性。

### KLEN
- **分类**: 微观结构
- **表达式**: `($high - $low) / $open`
- **说明**: K线实体长度（振幅），衡量当日价格波动范围。
- **使用建议**: 波动率替代指标，突然放大可能预示趋势启动或反转。

### KMID2
- **分类**: 微观结构
- **表达式**: `($close - $open) / ($high - $low + 1e-12)`
- **说明**: K线中位比例，收盘价在当日价格区间中的相对位置。接近1表示强势收盘。
- **使用建议**: 衡量日内多空争夺结果，极端值配合成交量使用效果更好。

### KUP
- **分类**: 微观结构
- **表达式**: `($high - Greater($open, $close)) / $open`
- **说明**: 上影线占比（相对开盘价），反映上方压力大小。
- **使用建议**: 上影线过长暗示卖压较强，可作为短期反转信号的组成部分。

### KUP2
- **分类**: 微观结构
- **表达式**: `($high - Greater($open, $close)) / ($high - $low + 1e-12)`
- **说明**: 上影线占整根K线的比例。
- **使用建议**: 与KUP含义类似但归一化方式不同，适合跨品种对比。

### KLOW
- **分类**: 微观结构
- **表达式**: `(Less($open, $close) - $low) / $open`
- **说明**: 下影线占比（相对开盘价），反映下方支撑强度。
- **使用建议**: 下影线长表示买方在低位积极承接，可作为支撑信号。

### KLOW2
- **分类**: 微观结构
- **表达式**: `(Less($open, $close) - $low) / ($high - $low + 1e-12)`
- **说明**: 下影线占整根K线的比例。
- **使用建议**: 跨品种归一化版本，适合因子合成时使用。

### KSFT
- **分类**: 微观结构
- **表达式**: `(2 * $close - $high - $low) / $open`
- **说明**: K线重心偏移率。正值表示收盘价偏向高位，负值偏向低位。
- **使用建议**: 衡量日内价格重心位置，结合KMID可判断K线质量。

### KSFT2
- **分类**: 微观结构
- **表达式**: `(2 * $close - $high - $low) / ($high - $low + 1e-12)`
- **说明**: K线重心在价格区间中的归一化位置。
- **使用建议**: 接近+1表示极强势收盘，接近-1表示极弱势收盘。

## 二、Price 因子（4个） — 当日价格归一化

当日价格数据相对收盘价的归一化值，窗口=0。

### OPEN0
- **分类**: 量价关系
- **表达式**: `$open / $close`
- **说明**: 开盘价与收盘价的比值。大于1表示高开低走（阴线），小于1表示低开高走（阳线）。
- **使用建议**: 跳空和日内趋势的基础指标。

### HIGH0
- **分类**: 量价关系
- **表达式**: `$high / $close`
- **说明**: 最高价与收盘价的比值。衡量日内上方偏离程度。
- **使用建议**: 数值越大表示当日上冲后回落越多，可能暗示短期顶部。

### LOW0
- **分类**: 量价关系
- **表达式**: `$low / $close`
- **说明**: 最低价与收盘价的比值。衡量日内下方偏离程度。
- **使用建议**: 数值越小表示当日下探后反弹越多，可能暗示短期底部。

### VWAP0
- **分类**: 量价关系
- **表达式**: `$vwap / $close`
- **说明**: 成交量加权平均价与收盘价的比值。
- **使用建议**: VWAP高于收盘价表示主力资金成本偏高，可能有回补动力。

## 三、Rolling 因子（145个） — 滚动窗口统计

29种统计类型 × 5个窗口 `[5, 10, 20, 30, 60]` = 145个因子。

**命名规则**: `{类型}_{窗口}`，如 `ROC_5`, `MA_10`, `STD_20`。

---

### 3.1 ROC — 动量（价格变化率）

- **分类**: 动量
- **表达式模板**: `Ref($close, {d}) / $close`
- **说明**: d日前收盘价与当前收盘价的比值。大于1表示近期下跌，小于1表示近期上涨。
- **使用建议**: 经典动量因子，短窗口(5)捕捉短期反转，长窗口(60)捕捉中期趋势。
- **变体**: `ROC_5`, `ROC_10`, `ROC_20`, `ROC_30`, `ROC_60`

### 3.2 MA — 均值回复（移动均线比）

- **分类**: 均值回复
- **表达式模板**: `Mean($close, {d}) / $close`
- **说明**: d日简单移动均线与当前价格的比值。大于1表示价格低于均线（超卖），小于1表示高于均线（超买）。
- **使用建议**: 经典均值回复指标。多窗口组合可构建均线交叉策略。
- **变体**: `MA_5`, `MA_10`, `MA_20`, `MA_30`, `MA_60`

### 3.3 STD — 波动率

- **分类**: 波动率
- **表达式模板**: `Std($close, {d}) / $close`
- **说明**: d日价格标准差（归一化）。衡量近期价格波动程度。
- **使用建议**: 低波动可能预示突破行情，高波动环境下动量策略效果通常下降。
- **变体**: `STD_5`, `STD_10`, `STD_20`, `STD_30`, `STD_60`

### 3.4 BETA — 动量（线性趋势斜率）

- **分类**: 动量
- **表达式模板**: `Slope($close, {d}) / $close`
- **说明**: d日窗口内价格的线性回归斜率（归一化），衡量趋势强度和方向。
- **使用建议**: 比ROC更稳健的趋势衡量方式，对噪声有平滑效果。
- **变体**: `BETA_5`, `BETA_10`, `BETA_20`, `BETA_30`, `BETA_60`

### 3.5 RSQR — 形态（趋势拟合度）

- **分类**: 形态
- **表达式模板**: `Rsquare($close, {d})`
- **说明**: d日线性回归的R²值，衡量价格走势的线性程度。接近1表示强趋势，接近0表示震荡。
- **使用建议**: 与BETA配合使用：高BETA+高RSQR=可靠趋势，高BETA+低RSQR=噪声。
- **变体**: `RSQR_5`, `RSQR_10`, `RSQR_20`, `RSQR_30`, `RSQR_60`

### 3.6 RESI — 波动率（回归残差）

- **分类**: 波动率
- **表达式模板**: `Resi($close, {d}) / $close`
- **说明**: d日线性回归的残差（归一化），衡量价格偏离线性趋势的程度。
- **使用建议**: 大残差可能预示趋势延续或短期超买超卖。
- **变体**: `RESI_5`, `RESI_10`, `RESI_20`, `RESI_30`, `RESI_60`

### 3.7 MAX — 形态（区间最高价）

- **分类**: 形态
- **表达式模板**: `Max($high, {d}) / $close`
- **说明**: d日最高价相对当前收盘价的比值，衡量近期高点距离。
- **使用建议**: 高值表示近期有显著回调，可能形成阻力位。
- **变体**: `MAX_5`, `MAX_10`, `MAX_20`, `MAX_30`, `MAX_60`

### 3.8 MIN — 形态（区间最低价）

- **分类**: 形态
- **表达式模板**: `Min($low, {d}) / $close`
- **说明**: d日最低价相对当前收盘价的比值，衡量近期低点距离。
- **使用建议**: 低值表示近期有显著反弹，可能形成支撑位。
- **变体**: `MIN_5`, `MIN_10`, `MIN_20`, `MIN_30`, `MIN_60`

### 3.9 QTLU — 形态（上分位数）

- **分类**: 形态
- **表达式模板**: `Quantile($close, {d}, 0.8) / $close`
- **说明**: d日价格的80%分位数（归一化），衡量价格在近期分布中的高位位置。
- **使用建议**: 比MAX更稳健的高位参考，减少极端值影响。
- **变体**: `QTLU_5`, `QTLU_10`, `QTLU_20`, `QTLU_30`, `QTLU_60`

### 3.10 QTLD — 形态（下分位数）

- **分类**: 形态
- **表达式模板**: `Quantile($close, {d}, 0.2) / $close`
- **说明**: d日价格的20%分位数（归一化），衡量价格在近期分布中的低位位置。
- **使用建议**: 比MIN更稳健的低位参考。
- **变体**: `QTLD_5`, `QTLD_10`, `QTLD_20`, `QTLD_30`, `QTLD_60`

### 3.11 RANK — 形态（价格百分位排名）

- **分类**: 形态
- **表达式模板**: `Rank($close, {d})`
- **说明**: 当前收盘价在过去d日中的百分位排名，范围0~1。
- **使用建议**: 接近1表示近期新高区域，接近0表示近期新低区域。
- **变体**: `RANK_5`, `RANK_10`, `RANK_20`, `RANK_30`, `RANK_60`

### 3.12 RSV — 均值回复（随机指标）

- **分类**: 均值回复
- **表达式模板**: `($close - Min($low, {d})) / (Max($high, {d}) - Min($low, {d}) + 1e-12)`
- **说明**: 随机指标（Raw Stochastic Value），当前收盘价在d日价格区间中的相对位置。
- **使用建议**: 类似KDJ中的RSV值。超过0.8为超买区，低于0.2为超卖区。
- **变体**: `RSV_5`, `RSV_10`, `RSV_20`, `RSV_30`, `RSV_60`

### 3.13 IMAX — 形态（最高价时间位置）

- **分类**: 形态
- **表达式模板**: `IdxMax($high, {d}) / {d}`
- **说明**: 过去d日最高价出现的相对时间位置。接近1表示最高点在窗口初期，接近0表示在末期。
- **使用建议**: 最高点位于窗口末期（值小）可能暗示上升趋势，位于初期（值大）可能暗示下降趋势。
- **变体**: `IMAX_5`, `IMAX_10`, `IMAX_20`, `IMAX_30`, `IMAX_60`

### 3.14 IMIN — 形态（最低价时间位置）

- **分类**: 形态
- **表达式模板**: `IdxMin($low, {d}) / {d}`
- **说明**: 过去d日最低价出现的相对时间位置。
- **使用建议**: 与IMAX对称使用，组合判断价格走势形态。
- **变体**: `IMIN_5`, `IMIN_10`, `IMIN_20`, `IMIN_30`, `IMIN_60`

### 3.15 IMXD — 动量（高低点时间差）

- **分类**: 动量
- **表达式模板**: `(IdxMax($high, {d}) - IdxMin($low, {d})) / {d}`
- **说明**: 最高价与最低价出现时间的标准化差值。正值表示先跌后涨，负值表示先涨后跌。
- **使用建议**: 反映近期价格运动的方向性节奏。
- **变体**: `IMXD_5`, `IMXD_10`, `IMXD_20`, `IMXD_30`, `IMXD_60`

### 3.16 CORR — 量价关系（价量相关性）

- **分类**: 量价关系
- **表达式模板**: `Corr($close, Log($volume + 1), {d})`
- **说明**: d日窗口内收盘价与成交量对数的相关系数。
- **使用建议**: 正相关（量价齐升）通常确认趋势；负相关（量价背离）可能预示反转。
- **变体**: `CORR_5`, `CORR_10`, `CORR_20`, `CORR_30`, `CORR_60`

### 3.17 CORD — 量价关系（价量变化率相关性）

- **分类**: 量价关系
- **表达式模板**: `Corr($close / Ref($close, 1), Log($volume / Ref($volume, 1) + 1), {d})`
- **说明**: d日窗口内价格变化率与成交量变化率的相关系数。
- **使用建议**: 比CORR更灵敏，捕捉增量资金与价格变化的同步性。
- **变体**: `CORD_5`, `CORD_10`, `CORD_20`, `CORD_30`, `CORD_60`

### 3.18 CNTP — 动量（上涨天数占比）

- **分类**: 动量
- **表达式模板**: `Mean($close > Ref($close, 1), {d})`
- **说明**: 过去d日中收盘价高于前日的天数占比，范围0~1。
- **使用建议**: 高值表示持续上涨，可衡量趋势持续性。
- **变体**: `CNTP_5`, `CNTP_10`, `CNTP_20`, `CNTP_30`, `CNTP_60`

### 3.19 CNTN — 动量（下跌天数占比）

- **分类**: 动量
- **表达式模板**: `Mean($close < Ref($close, 1), {d})`
- **说明**: 过去d日中收盘价低于前日的天数占比。
- **使用建议**: 与CNTP互补，CNTP+CNTN<1时存在平盘日。
- **变体**: `CNTN_5`, `CNTN_10`, `CNTN_20`, `CNTN_30`, `CNTN_60`

### 3.20 CNTD — 动量（涨跌天数差）

- **分类**: 动量
- **表达式模板**: `Mean($close > Ref($close, 1), {d}) - Mean($close < Ref($close, 1), {d})`
- **说明**: 上涨天数占比减去下跌天数占比，范围-1~1。
- **使用建议**: 正值且绝对值大表示单边上涨趋势，是趋势一致性的度量。
- **变体**: `CNTD_5`, `CNTD_10`, `CNTD_20`, `CNTD_30`, `CNTD_60`

### 3.21 SUMP — 均值回复（上涨幅度占比）

- **分类**: 均值回复
- **表达式模板**: `Sum(Greater($close - Ref($close, 1), 0), {d}) / (Sum(Abs($close - Ref($close, 1)), {d}) + 1e-12)`
- **说明**: d日内累计涨幅占累计总波动的比例，类似RSI的分子部分。
- **使用建议**: 高值(>0.7)为超买信号，低值(<0.3)为超卖信号。
- **变体**: `SUMP_5`, `SUMP_10`, `SUMP_20`, `SUMP_30`, `SUMP_60`

### 3.22 SUMN — 均值回复（下跌幅度占比）

- **分类**: 均值回复
- **表达式模板**: `Sum(Greater(Ref($close, 1) - $close, 0), {d}) / (Sum(Abs($close - Ref($close, 1)), {d}) + 1e-12)`
- **说明**: d日内累计跌幅占累计总波动的比例。SUMP + SUMN ≈ 1。
- **使用建议**: 与SUMP对称使用。
- **变体**: `SUMN_5`, `SUMN_10`, `SUMN_20`, `SUMN_30`, `SUMN_60`

### 3.23 SUMD — 均值回复（涨跌幅度差，RSI变体）

- **分类**: 均值回复
- **表达式模板**: `SUMP_{d} - SUMN_{d}`
- **说明**: 上涨幅度占比减去下跌幅度占比，本质是RSI的线性变换。范围-1~1。
- **使用建议**: 等价于 `2 * RSI - 1`，正值为多头主导，负值为空头主导。
- **变体**: `SUMD_5`, `SUMD_10`, `SUMD_20`, `SUMD_30`, `SUMD_60`

### 3.24 VMA — 流动性（成交量均线比）

- **分类**: 流动性
- **表达式模板**: `Mean($volume, {d}) / ($volume + 1e-12)`
- **说明**: d日平均成交量与当日成交量的比值。大于1表示今日缩量，小于1表示今日放量。
- **使用建议**: 放量突破、缩量回调等经典量价模式的基础指标。
- **变体**: `VMA_5`, `VMA_10`, `VMA_20`, `VMA_30`, `VMA_60`

### 3.25 VSTD — 流动性（成交量波动率）

- **分类**: 流动性
- **表达式模板**: `Std($volume, {d}) / ($volume + 1e-12)`
- **说明**: d日成交量标准差（归一化），衡量成交量的波动程度。
- **使用建议**: 高值表示成交量不稳定，可能伴随重要事件驱动。
- **变体**: `VSTD_5`, `VSTD_10`, `VSTD_20`, `VSTD_30`, `VSTD_60`

### 3.26 WVMA — 波动率（量价联合波动）

- **分类**: 波动率
- **表达式模板**: `Std(Abs($close / Ref($close, 1) - 1) * $volume, {d}) / (Mean(Abs($close / Ref($close, 1) - 1) * $volume, {d}) + 1e-12)`
- **说明**: 成交量加权价格变化的波动率，衡量量价联合波动的稳定性。
- **使用建议**: 捕捉大资金异动，比单纯价格或成交量波动率更有信息量。
- **变体**: `WVMA_5`, `WVMA_10`, `WVMA_20`, `WVMA_30`, `WVMA_60`

### 3.27 VSUMP — 量价关系（成交量上升占比）

- **分类**: 量价关系
- **表达式模板**: `Sum(Greater($volume - Ref($volume, 1), 0), {d}) / (Sum(Abs($volume - Ref($volume, 1)), {d}) + 1e-12)`
- **说明**: d日内成交量增长幅度占总变化的比例，成交量版RSI。
- **使用建议**: 高值表示持续放量，低值表示持续缩量。
- **变体**: `VSUMP_5`, `VSUMP_10`, `VSUMP_20`, `VSUMP_30`, `VSUMP_60`

### 3.28 VSUMN — 量价关系（成交量下降占比）

- **分类**: 量价关系
- **表达式模板**: `Sum(Greater(Ref($volume, 1) - $volume, 0), {d}) / (Sum(Abs($volume - Ref($volume, 1)), {d}) + 1e-12)`
- **说明**: d日内成交量缩减幅度占总变化的比例。
- **使用建议**: 与VSUMP互补，组合使用判断量能方向。
- **变体**: `VSUMN_5`, `VSUMN_10`, `VSUMN_20`, `VSUMN_30`, `VSUMN_60`

### 3.29 VSUMD — 量价关系（量能方向强度）

- **分类**: 量价关系
- **表达式模板**: `VSUMP_{d} - VSUMN_{d}`
- **说明**: 成交量上升占比减去下降占比，衡量近期量能的净方向。范围-1~1。
- **使用建议**: 正值配合价格上涨=量价配合良好；正值配合价格下跌=量价背离。
- **变体**: `VSUMD_5`, `VSUMD_10`, `VSUMD_20`, `VSUMD_30`, `VSUMD_60`
