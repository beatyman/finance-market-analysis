# 两日对比分析框架 + 韩国强平诊断

用于反转日/突破日/强平日的快速诊断。

## 分析维度

1. **指数**: 上证/创业板/科创50/沪深300 涨跌幅
2. **期指**: IF/IC/IM/IH 主力合约 涨跌+持仓变化 → 判断空头回补/多头进场
3. **期权**: 虚值归零合约 OI → Gamma squeeze判断
4. **港股**: 沽空率变化趋势 + 港股指数方向
5. **CSI300信号**: 中枢内买数量变化、A/B级分布
6. **核心持仓**: 中枢内/外状态变化
7. **ETF动量**: 反转日是否改变动量排名

## 韩国强平时序框架

```
misu交易:    急跌触发 → T+2未结清 → T+3折扣强平(15-30%)
margin loan: 跌破140%维持担保比 → 1-2日宽限 → 集中执行

日历映射:
  急跌日(D)      → 触发杠杆但不强平
  D+1(反弹)      → 真空窗口, 非真正筑底
  D+2~D+3        → 真正压力日, 扛住=真底部

2026-07-13案例:
  7/13(一) 急跌−2.06% → 7/14(二)反弹+2.15%(真空) → 7/15(三)科创50−4.25% 沪深300−0.20%
```

## 期指空头回补诊断

关键信号: **四大期指全线减仓+上涨 = 空头回补**

| 条件 | 判断 |
|------|------|
| IF/IC/IM/IH全线涨 + 持仓全线下降 | 空头集体平仓(shorts covering) |
| 涨 + 持仓上升 | 新增多头入场(long buildup) |
| 跌 + 持仓上升 | 空头加仓, 下跌延续 |
| 涨 + IM减仓最大 | 小盘空头最慌, 被迫cut |

## Gamma到期效应

- 月合约到期日 → Put集中归零 → 做市商买入期货平仓对冲 → 助推指数反弹
- **定性: 短期效应, 次日无Gamma助推后回归基本面**
- 判断: 看归零Put的总OI规模, OI>5000手有明显助推
