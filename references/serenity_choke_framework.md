# A股卡脖子选股框架（吸收 serenity-stock-choke / Serenity 供应链瓶颈理论）

> **核心命题**："沿着产业链向上游追溯，找到那个'一旦断货，万亿产业就要地震'的关键节点——那个节点上的小盘股，就是下一个暴击机会。"

来源：Reddit 传奇人物 Serenity（@aleabitoreddit），RISC-V+AI 框架 2019-2024 约 3800% 收益率。原版战绩：AXT Inc（InP衬底全球唯三）+525%、AAOI（CPO激光器）+348%。

**定位**：这是**供应链地缘政治分析**，不是基本面投资，也不是技术分析。与缠论（定结构/买卖点）和 XGBoost（打分）互补——本框架回答"买什么赛道"，缠论回答"什么位置买"。

---

## 一、核心逻辑（三步）

```
① AI大爆发 / 政策驱动 / 技术跃迁
    ↓
② 上游硬件/原材料需求暴增，供应链某些环节产能跟不上
    ↓
③ 瓶颈环节掌握定价权 → 其中小盘股弹性最大
```

**霍尔木兹海峡类比**：霍尔木兹是全球石油咽喉，一旦封锁所有人受影响，但拥有海峡股份的人掌握定价权。→ A股翻译：哪个环节是某大赛道的"霍尔木兹"？哪个公司控制它？

---

## 二、六步分析链路

### 第一步：定位板块周期（三种类型）

| 类型 | 特征 | 信号 | 典型 |
|---|---|---|---|
| **需求爆发期** | 终端需求暴增，中游扩产来不及 | 价格上涨、订单排到几年后 | AI算力、固态电池 |
| **技术跃迁期** | 新技术替代旧技术 | 政策打压旧、补贴新 | CPO替代可插拔、HJT替代PERC |
| **供给受限期** | 关键原材料被卡/产能有限 | 报价暴涨、份额成壁垒 | InP衬底、氦气、高纯石英 |

### 第二步：溯源供应链，定位卡脖子节点

**溯源模板**（每个板块过一遍）：
```
终端产品 → 最终组装/集成（产能集中度？）→ 核心零部件（技术壁垒？）
         → 关键材料/元器件（原料依赖？）→ 上游化工/矿产/稀有气体（资源垄断？）
```

**六条"易卡脖子"判断标准**（满足越多越硬）：
1. ✅ 技术壁垒极高（专利林立、know-how 积累深）
2. ✅ 产能建设周期长（2-5 年扩产窗口）
3. ✅ 国内自给率低（依赖进口）
4. ✅ 单一供应商或寡头垄断
5. ✅ 不可替代性高（无备选方案）
6. ✅ 地缘政治风险（出口管制、制裁）

### 第三步：找 A 股标的（四维信号卡）

| 维度 | 要查什么 |
|---|---|
| 卡脖子定位 | 该环节份额/技术壁垒/专利 |
| 估值水位 | P/E、P/B 在板块内分位 |
| 资本信号 | 主力净流入、融资融券、龙虎榜 |
| 机构关注度 | 近期研报覆盖、目标价 |

### 第四步：真伪筛选（六条排除规则，一条即剔除）

| # | 排除条件 | 典型案例 |
|---|---|---|
| 1 | 有业务但不是主营（蹭热点） | 主营电缆突然说做CPO |
| 2 | 竞争格局分散，无护城河 | 大量同质化小厂 |
| 3 | 产能扩张太容易（壁垒低） | 通用型原材料 |
| 4 | 进口替代逻辑不成立（国外也无货） | 全球都缺的氖气 |
| 5 | 估值已充分反映（过于知名） | 龙头都已大涨 |
| 6 | 无机构关注（流动性陷阱） | 日均成交额<5000万 |

### 第五步：多空双向确认（不做单边多头）

| 做多信号 | 做空/观望信号 |
|---|---|
| ✅ 板块主力净流入持续 | ❌ 板块主力净流出 |
| ✅ 机构开始覆盖（研报出现） | ❌ 无研报、无人问津 |
| ✅ 产能建设周期>2年 | ❌ 产能半年可达 |
| ✅ 政策明确支持 | ❌ 政策压制 |
| ✅ 筹码集中度提升 | ❌ 股东人数暴增 |
| ✅ 估值分位低于板块平均 | ❌ P/E > 历史80%分位 |

### 第六步：输出报告（七部分）

板块周期判断 → 卡脖子地图 → 候选标的四维信号卡 → 筛选结论 → 多空对照 → 今日资金面 → 操作建议（短线/中线/长线各一句+风险）。

## 三、A股特色适配（vs 美股原版）

| 维度 | 美股 | A股 |
|---|---|---|
| 政策权重 | 低 | **极高**（政策直接催化） |
| 主力资金 | 对冲基金/机构 | 公募+私募+**游资**（炒作凶猛） |
| 散户 | 少 | 高，情绪波动大 |
| 壳资源 | 无 | 小市值有壳价值溢价 |
| 国产替代 | 非核心 | **核心逻辑之一**（卡脖子清单） |

**A股独有信号**：龙虎榜（游资席位）、融资融券（杠杆态度）、主力净流入>5亿（机构建仓）、政府工作报告（3月方向）、国务院卡脖子清单。

## 六、风险提示

1. 小盘股单日涨跌 20-30% 常见，波动极大
2. 逻辑验证可能需 1-3 年，需耐心
3. 供应链信息真伪难辨，需独立验证
4. A股受政策影响显著，紧盯监管动态
5. 不适用：纯题材炒作（无产业逻辑）、预测大盘、精确估值（亏损/早期公司）
