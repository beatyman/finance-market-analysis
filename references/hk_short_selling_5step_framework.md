# 港股沽空率 × 缠论 × SMC 五步交叉框架

基于2026-07-05/06腾讯/阿里/美团/快手/小米五只实战验证的系统方法论。

## 五步分析流程

### Step 1: 缠论结构定位
```
chan_engine.analyze() → BSP信号 + 中枢位置 + 笔方向
判断: 底部(一买/中枢内买) / 中继(中枢外) / 顶部(二卖/Sell)
```

### Step 2: SMC聪明钱验证
```
scan_one(high,low,open_,close,direction='bottom')
→ score(0-3) + PDA(OB/FVG/OB+FVG) + 三推 + 三重背离
判断: 聪明钱确认(≥0.5) / 未确认(0)
```

### Step 3: 沽空率趋势分析
```
关键指标:
- 沽空率绝对值: <15%=安全, 15-25%=谨慎, >25%=危险
- 沽空率趋势: ↓下降=空头撤退(好), ↑上升=空头加仓(坏), →走平=对峙
- 沽空率峰值vs当前: 从峰值降>50%=空头投降
- 3日/5日均线变化: 确认趋势方向

价格×沽空率交叉:
  价↑沽空率↓ = 轧空(最强看涨)  ← 快手
  价↑沽空率↑ = 背离诱多(最危险) ← 美团
  价↓沽空率↓ = 空头获利了结
  价↓沽空率↑ = 空头加码(继续看跌) ← 小米
```

### Step 4: 五只交叉对比
```
同向信号确认: 四只同向+ETF沽空56%=系统性做空
异向信号分化: 快手的空头逃亡 vs 美团空头坚守 → 选快手
```

### Step 5: 综合多空判定
```
三重看多(可建仓):
  ✅ 缠论一买/中枢内买
  ✅ 沽空率<15%且趋势↓
  ✅ SMC≥0.5或PDA命中

三重看空(不参与):
  ❌ 缠论Sell二卖
  ❌ 沽空率>25%且顽固不降
  ❌ SMC=0分
```

## 关键教训

1. **反弹≠空头投降**: 恒指反弹日四股沽空率同步跳升 → 空头利用拉升加仓
2. **单日沽空率不可靠**: 6/26腾讯6.1%→判断"最接近底部"→3天后跳回16.8%
3. **只有连续5日趋势+缠论信号+Call承接→三重确认才算底部**
4. **沽空率>20%且顽固不降=不可操作**(美团26%零变化)
5. **沽空率从峰值暴跌>50%+价格反弹=最佳机会**(快手370%→15%)

## 数据格式(AAStocks粘贴TSV)

用户粘贴15日沽空数据时,从TSV中提取:
```
日期 | 价格 | 升跌 | 升跌% | 沽空股数 | 沽空金额 | 成交金额 | 占大巿 | 沽空比率 | 3日均 | 5日均
```

⚠️ "占大巿沽空比率"是占全市场沽空比率,不是个股沽空率。个股沽空率=沽空金额/成交金额(需额外计算或依赖"沽空比率"列)。
