# 个股深度研究框架（吸收 equity-research-skill）

> 机构级投研框架。核心是**预期差投资**（Expectations Investing, Rappaport & Mauboussin）——"股价不是对未来的预测，而是一组已定价的预期"。补上 a-share-market-analysis 缺的"深度基本面估值 + 财务造假识别"。

---

## 一、预期差分析主线（第一章开篇框架）

**三步**：
1. **解码市场预期**（不预测，只解码）：反向 DCF 解出现价隐含的稳态 FCF/营收/CAGR；PVGO 分解 `现价 = 零增长价值(E/r) + 增长期权(PVGO)`，算现价有多少百分比在给"尚未发生的增长"付费。
2. **建立自己预期**：每个关键驱动查历史 base rate 分位，超越须给结构性理由（"管理层有信心"不算）。
3. **陈述预期差 + 修正路径**：分歧写成可证伪命题"市场认为 X，我认为 Y，因证据 Z，验证信号 W(时点)"。

**Gap 表（必备交付物）**：营收 CAGR / 稳态利润率 / ROIIC / 永续 g → 市场隐含 vs 我的预期 vs base rate 分位 → 净预期差方向。

**独立观点检验三问**（答不出只能"观望"）：
1. 与共识最大单一分歧是什么？
2. 分歧为何存在（市场犯了什么可识别的错）？
3. 若我错，最早何时通过什么数据发现？

## 二、财报质量核查（先验真后估值，scripts/beneish_mscore.py）

**Beneish M-Score 八变量**（盈余操纵概率）：

```
M = −4.84 + 0.92·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI
    + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI
```

| 变量 | 含义 | 危险方向 |
|---|---|---|
| DSRI | 应收/收入指数 | ↑ 提前确认收入 |
| GMI | 毛利率指数 | ↑ 毛利率恶化诱发操纵 |
| AQI | 资产质量指数 | ↑ 费用资本化 |
| SGI | 收入增长指数 | ↑ 高增长动机更强 |
| DEPI | 折旧率指数 | ↑ 放慢折旧 |
| SGAI | 费用率指数 | ↑ 效率恶化 |
| TATA | 总应计/总资产 | ↑ 权重最大项 |
| LVGI | 杠杆指数 | ↑ 违约压力 |

**判读**：M > -1.78 → "可能操纵"区（移入逐项手工核查）。金融股不适用。

**应计质量**：总应计比率 = (净利润−CFO)÷总资产，>10% 红旗；现金转化率 CFO÷净利润 长期 <80% 须解释。

**财报可信度评级（预注册否决项）**：

| 等级 | 判定 | 强制作用 |
|---|---|---|
| A | 无红旗 + 现金转化≥90% | 无限制 |
| B | 1-2 项轻度红旗 | 列入监控 |
| C | M-Score 越限 / DSO 背离 / 治理红旗 | **动作最高"观望"** |
| D | 多项严重红旗 / 造假证据 | **规避**，估值无意义 |

## 三、结论标定规则（预注册，不得临场发挥）

**估值标签**（综合区间 [L,H]，现价 P，±15% 缓冲）：

| 条件 | 标签 |
|---|---|
| P < 0.50L | 显著低估 |
| 0.50L ≤ P < 0.85L | 低估 |
| 0.85L ≤ P ≤ 1.15H | 合理 |
| 1.15H < P ≤ 1.50H | 高估 |
| P > 1.50H | 显著高估 |

**仓位思维**：不对称比 = 上行空间÷下行空间（<1.5 的"低估"不值得建仓）；Kelly-lite 参考仓位 = ¼×Kelly，上限 15%。

**合理倍数纪律（warranted multiple）**：不许抄同业中位数。稳态下合理 P/E ≈ (1−g/ROIIC)/(r−g)，差额要么是市场错（机会）要么是没看到的风险（警报）。

## 四、与 a-share-market-analysis 的融合

| 本项目 | 融合到已有体系 |
|---|---|
| **Beneish M-Score** | `beneish_mscore.py`——财务造假定量检测，补基本面六项评分的"质量"维度 |
| **财报可信度 A/B/C/D** | 预注册否决项，↔ 阿娇否决（C/D 级一票降级） |
| **预期差分析** | 反向 DCF + PVGO，补"现价隐含什么"的估值锚 |
| **结论标定规则** | 估值标签 + 动作矩阵，预注册（↔ 阿娇否决哲学一致） |

**核心增量**：`beneish_mscore.py`（M-Score 八变量）+ 财报可信度评级。**"先验真后估值"**——你的基本面六项评分（PE/PB/ROE）是"数字打分"，但没检查"利润是不是真的"。M-Score 补上"财务造假检测"，让基本面评分不再被假利润欺骗。
