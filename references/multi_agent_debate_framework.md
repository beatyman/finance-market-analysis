## 三、三方风控辩论框架（最硬核）

### 保守（Conservative）— 6个A股下行风险
1. **T+1 锁仓**（最重要的结构性风险）：今日持仓明日才能卖，跳空低开（隔夜政策/全球暴跌）亏损锁死无补救
2. **涨跌停陷阱**：跌停板买单空、卖单排队难成交；**2026-07-06 后盘后固定价时段(15:05-15:30，收盘价)覆盖全A股**——跌停日"实际上被困"而非"无法下单"，但仍是"有效被困"（取决于有无对手盘）。连续跌停可致灾难性损失
3. **解禁压制**：大额解禁即使内部人未卖，卖出的"期权"本身就压制情绪、封顶上行
4. **政策反转**：政策市给的也能一夜收回，板块扶持→整顿只差一纸国务院文件
5. **游资撤离**：游资双向都快，今日涨停明星明日跌停，散户最后才知道
6. **估值纪律**：PE>50x+PEG>2 无论如何都是投机，30x PE 消化框架是锚——若需5年+消化则高估

### 中性（Neutral）— 6个平衡考量
1. **T+1 双刃剑**：锁损（保守）但也防恐慌抛售、助多日动量（激进）——中性：仓位要能扛单次跳空
2. **政策信号分级**：国务院文件（高置信）> 地方政府激励（低可靠）> 市场谣言（噪声），按此加权
3. **北向=聪明钱但更易变**：比散户更懂，但撤退比内资快——作 confirming signal 不作 primary thesis
4. **估值带而非硬阈值**：不问"PE>30x就贵"，问"给定盈利轨迹，什么PE区间可辩护"
5. **解禁时机**：不在解禁日恐慌，监控实际减持公告（减持公告），解禁窗口渐进减仓而非全进全出
6. **板块轮动周期**：A股题材轮动快（通常2-4周），判断"轮动早段（有空间）vs 晚段（上行空间小+下行风险大）"

### 激进（Aggressive）— 6个A股做多论据
1. **涨停板效应**：连板产生强动量，T+1 反而防当日获利了结，助多日连涨
2. **政策兜底板块**：北京背书（AI/芯片/新能源）时政策底真实存在，西方市场没有的"政策 floor"
3. **游资确信度**：顶级游资席位+强题材归因涌入，短期爆发力强，错过也是风险
4. **北向验证**：外资净买+内资动量 = 双重确认强信号
5. **PE 扩张阶段**：A股牛市题材龙头 PE 常规扩到 50-100x，过早套用美股估值纪律=错过主升浪
6. **散户情绪顺风**：A股 80% 散户，情绪转正时羊群效应放大涨幅远超基本面

## 与 a-share-market-analysis 的整合

这套辩论框架的本质是**强制多空对冲思考 + 风险分层**，与用户"多系统交叉验证"、"规避风险"哲学一致：

1. **买入前自问**：多头5催化哪几条成立？空头6风险哪几条存在？—— 只买"多头催化≥3 且空头风险≤2"的标的
2. **持仓时用保守框架**：T+1锁仓 + 涨跌停陷阱 + 解禁压制 = 决定"最多亏多少"
3. **轮动周期判断**：中性框架的"轮动早段/晚段"决定加仓还是减仓
