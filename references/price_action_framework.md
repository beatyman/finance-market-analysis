# Price Action 分析框架（吸收 price-action-skill）

> 整合 ICT（智能钱）+ GEX/Gamma（期权对冲）+ 经典价格行为 + VWAP 四支柱的机构级分析框架。与 smc-ict-trading（Bias→Setup→评分系统）互补：本框架补 GEX/VWAP/输出模式/级别优先级。

---

## 一、四支柱速查

### 1. ICT 概念（Smart Money Concepts）

| 术语 | 定义 | 用法 |
|---|---|---|
| **SSL（卖方流动性）** | 前低/等低/明显支撑下方 | 价格扫 SSL 诱空 → 反转向上（"聪明钱先扫止损再走真方向"） |
| **BSL（买方流动性）** | 前高/等高/明显阻力上方 | 扫 BSL 诱多 → 反转向下 |
| **FVG（公允价值缺口）** | 三根K线：K1高点与K3低点之间的缺口（多）/ K1低点与K3高点（空） | 价格常回补 FVG；未补 FVG 靠近关键结构 = 高确信入场 |
| **Displacement（位移）** | 脱离震荡区的强冲动，常留 FVG | 位移 + FVG 回踩 = ICT 经典入场模型 |
| **CISD（交付状态变化）** | 多空交付切换，由位移K线收盘破前结构 + FVG 确认 | 扫 SSL/BSL 后出现 = 高概率 |
| **BOS（结构突破）** | 同向延续信号 | 趋势延续 |
| **CHoCH（性质变化）** | 反向反转信号 | 趋势反转 |

**核心原则**：自上而下读结构——先 HTF（日线/4H）定方向，再 LTF（1H/15m/5m）找入场。

### 2. GEX/Gamma 机制（期权做市商对冲）

> 做市商 delta 对冲期权敞口，在 gamma 集中区产生可预测的价格行为。**美股/港股期权有效，A股个股不适用**（A股无个股期权做市生态，但可映射到 50ETF/300ETF 期权）。

| 概念 | 机制 |
|---|---|
| **Call Wall（正 gamma）** | 大 call 持仓行权价 = 做市商涨时卖 delta → 阻力，难破 |
| **Put Wall（正 gamma）** | 大 put 持仓 = 做市商跌时买 delta → 支撑 |
| **零 Gamma 线** | 净 gamma 正负翻转点；下方波动放大、加速；上方压缩、均值回归 |
| **HVL（高成交量位）** | 做市商定位锚 |
| **GEX+ICT 融合** | 流动性扫荡更可能在 gamma 墙反转；FVG 回踩 + gamma 支撑 = 最高确信入场 |

**Edge cases**：低 GEX/OPEX 周 gamma 墙不牢、区间放大、ICT 结构权重提升；0DTE 时 gamma 效应极强（墙近似硬顶/硬底）。

### 3. 经典价格行为

- **结构**：HH+HL=上涨，LH+LL=下跌；区间=高抛低吸或突破
- **支撑阻力**：测试次数越多越弱（流动性耗尽）；**新鲜未测位 > 反复测过的位**
- **K线形态**：关键位长上影（拒绝）= 反转信号；扫流动性后吞没 = 入场触发；结构处十字星 = 等确认
- **成交量**：突破放量 = 真；缩量突破 = 假突破（高 GEX 下更常见）；S/R 处量枯 = 吸筹/派发

### 4. VWAP + 盘前流动性 + 开盘区间

| 概念 | 用法 |
|---|---|
| **VWAP** | 机构平均成本基准；价在 VWAP 上方 = 日内偏多；**VWAP 收复**（跌破后收回）= 做多触发；**VWAP 拒绝** = 偏空 |
| **PMH/PML（盘前高低）** | PMH=买方流动性池，PML=卖方池；扫 PML 后 VWAP 收复 = 做多模型 |
| **开盘区间（首 5-30 分钟）** | ORH/ORL = 日内流动性位；放量突破 OR = 趋势日；OR 拒绝 = 震荡日 |
| **ICT 时段** | 9:30-10:00、10:00-11:00、14:00-15:00（美股 EST，A股映射 9:30-10:00、10:30-11:00、14:00-15:00） |

## 二、分析工作流（Top-Down 六步）

```
1. HTF Bias（日线/4H）    → 趋势方向、主要 S/R、近期 BOS/CHoCH
2. GEX Context            → gamma 正负、关键墙、零 gamma 线（美股/港股）
3. 日内结构（1H/15m）      → 摆动高低、FVG、位移区
4. 流动性地图             → SSL/BSL 池在哪？PMH/PML？VWAP？
5. 触发（5m/1m）          → 流动性扫荡 + FVG 回踩，或 VWAP 收复
6. 共振计数               → 框架对齐越多 = 确信越高（3+ = 高确信）
```

## 三、交易设置生成模板（必含字段）

| 字段 | 说明 |
|---|---|
| Instrument | 标的 |
| Bias | 方向 + 自上而下理由 |
| Entry trigger | 精确条件（如"5m 收盘回补 FVG 于 SSL 扫荡后"） |
| Entry zone | 价格区间 |
| Stop | 止损位 + 为什么失效 |
| T1 | 第一目标（最近流动性/gamma 墙） |
| T2 | 延伸目标（下一主级别） |
| Invalidation | 入场前什么价格行为会否定 |
| Timeframe | 设置有效窗口 |
| Conviction | 低/中/高 + 理由 |

## 四、级别优先级栈（多级别聚集时排序）

```
1. GEX gamma 墙（做市商对冲最硬）
2. 日线/周线 S/R（HTF 最高）
3. SSL/BSL 池（流动性磁铁）
4. FVG（回踩区）
5. VWAP / PMH / PML（日内锚）
6. 经典 S/R / 整数关口（群体心理）
```

**共振 3+ = 高确信级别。**

## 五、输出模式

### Mode A — 结构化分析（研究/交易计划/Discord 分析帖）
```
BIAS: [Bullish/Bearish/Neutral] — 一句话理由
KEY LEVELS: [级别 + 类型]
SETUP: Entry trigger / zone / Stop / Target / Invalidation
NARRATIVE: 2-4 句串联（结构→级别→催化）
```

### Mode B — 社区帖（富途牛牛/Discord）
- 第一人称、同行口吻，**不爹味**（"我自己的理解是..."，不"大家注意了"）
- 纯文本无 markdown，短句，反直觉开头
- 不给明确买卖指令，框定为个人观察

### Mode C — 日内复盘
- 叙事段、过去时、事实语气，<200 字
- 覆盖：开盘行为、关键级别互动、量能背景、收盘结构

## 六、与 a-share-market-analysis 的融合映射

| 本框架概念 | 映射到已有体系 |
|---|---|
| ICT SSL/BSL 扫荡 | 缠论"三买三卖"的假突破识别（扫止损再反转） |

| 级别优先级栈 | 缠论中枢 > XGBoost 打分 > 筹码峰 > 资金流的共振 |
