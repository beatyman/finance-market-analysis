## 一、政策分析框架（政策市 — 权重最高因子）

A股是全球最典型的「政策市」，政策分析是投资决策中权重最高的因子之一。

### 五层政策
| 层级 | 内容 |
|---|---|
| 宏观政策 | 货币（降准/降息/MLF/LPR）、财政（专项债/减税）、汇率（升贬值对进出口影响） |
| 监管政策 | 证监会（IPO节奏/再融资/减持新规/退市）、银保监（信贷）、发改委（产业审批） |
| 产业政策 | 国务院/部委行业扶持或限制（新质生产力/半导体自主可控/新能源补贴/地产调控/平台监管） |
| 地方政策 | 区域性扶持（自贸区/特区优惠/地方产业基金） |
| 国际政策 | 中美关系/出口管制/关税/制裁的传导效应 |

### 力度分级
```
指导意见(弱) < 部委通知(中) < 国务院文件(强) < 法律法规(最强)
```

### 时间窗口
```
短期脉冲(1-2周) vs 中期趋势(1-3月) vs 长期结构性(半年+)
```

### 分析方法
1. 识别近期与目标公司直接/间接相关的政策
2. 评估力度级别
3. 判断影响时间窗口
4. 分析受益/受损逻辑链：政策 → 行业影响 → 公司业务映射 → 财务影响估算

## 二、游资/资金博弈分析框架

追踪成交量异动、股东变化、市场新闻，判断短期资金博弈格局。

### 龙虎榜信号
- 知名游资席位的买入 = 强势信号
- 通过股东变化和交易数据推断机构/游资席位动向

### 资金博弈格局（四分类）
```
主力吸筹 / 主力出货 / 游资接力 / 散户主导
```

## 三、解禁/减持分析框架（供给端压力）

追踪限售股解禁计划、大股东减持动态、股权结构变化，评估供给端压力。

### 解禁规模评估
- 解禁市值占流通市值 **>20% = 重大解禁压力**；<5% = 影响有限
- 结合当前股价和解禁成本（原始获取价）判断减持动力

### ⚠️ 2024减持新规三条禁止减持情形（《上市公司股东减持股份管理暂行办法》第十条/十一条）
控股股东、实控人出现下列任一情形，**不得通过集中竞价或大宗交易减持**：
1. **破发**：最近20个交易日任一日收盘价（向后复权）低于 IPO 发行价
2. **破净**：最近20个交易日任一日收盘价（向后复权）低于最近一期每股净资产
3. **分红不达标**：最近三个已披露经审计年度未现金分红，或累计现金分红低于同期年均归母净利润的30%（净利润为负的年度不计入）

> **判断解禁压力时必须先核对这三条** —— 若触发，控股股东减持路径实际被封死，解禁市值再大也不等于即时抛压。

### 减持动力评估
- 当前股价 vs 解禁成本的溢价倍数越高，减持动力越强
- 股价低于解禁成本 → 减持概率大幅降低

### 历史减持行为
- 大股东过往减持频率和规模反映套现意愿，频繁减持者新一轮解禁减持概率更高

## 四、多空辩论 + 三方风控辩论结构

### 多头 vs 空头研究员（Bull ←→ Bear，最多 N 轮）
两套对立框架交叉验证，分歧处补证，最终收敛或暴露风险。

### 三方风控辩论（保守 / 中性 / 激进）
- **保守（Conservative）**：强调下行保护、安全边际
- **中性（Neutral）**：平衡风险收益
- **激进（Aggressive）**：强调上行机会、动量

三方辩论后由交易员做最终决策，风控意见影响仓位与止损。

## 五、A股交易规则约束（操作计划必检）

| 规则 | 影响 |
|---|---|
| T+1 | 当日买入不可当日卖出 |
| 涨跌停 | 主板±10%（ST±5%，创业板/科创板±20%） |
| 最小手数 | 100股整数倍 |
| ST 股 | 风险警示，±5%限制，退市风险 |

## 与 a-share-market-analysis 的整合

现有体系是**技术面**（缠论+XGBoost+四框架）+ **风险引擎**（risk_engine）+ **专家透镜**（stock-analysis）。本框架补充三大 A股特有维度：

1. **政策面**：选股前先查产业政策方向（如"新质生产力"利好半导体/新能源，"地产调控"利空地产链）
2. **游资面**：结合量价分析判断资金博弈格局（龙虎榜游资接力 vs 主力出货）
3. **解禁面**：买入前必查未来90天解禁日历 + 2024减持新规三条（破发/破净/分红不达标）

**优先级建议**：政策面（权重最高）> 游资面（短期节奏）> 解禁面（供给压力），三者作为阿娇筛选的**前置否决项**（解禁重大压力 → 即使缠论买点也不做）。
