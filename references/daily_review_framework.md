# A股每日市场情绪复盘框架（吸收 a-stock-daily-review）

> 市场情绪温度计——补上 a-share-market-analysis 缺的"情绪维度"。选股是"个股维度"（XGB×共振×资金流×R:R×基本面），但缺"市场情绪维度"的约束：**情绪退潮时，再好的个股信号也要降仓**。

---

## 一、市场情绪六步复盘

1. **整体情绪**：涨停/炸板/跌停 + 炸板率，昨涨停溢价与晋级率 → 容错率
2. **连板梯队**：最高板、各板数家数、梯队是否断层 → 高标断板风险
3. **板块结构**：3 只以上涨停=强势板块，区分新爆发/延续扩散/退潮
4. **资金流向**：成交额前排 + 龙虎榜净买/净卖 + 机构 vs 游资席位
5. **亏钱效应**：炸板振幅与次数、昨涨停大面、全市场大跌
6. **风向标**：强方向标的（最多10只），标注观察点

---

## 二、核心数据接口（东财 push2ex）

| 数据 | 端点 | 关键字段 |
|---|---|---|
| 涨停池 | `push2ex.eastmoney.com/getTopicZTPool` | `lbc`连板数/`zbc`炸板次数/`hybk`行业/`zttj`N天M板/`fund`封板资金 |
| 炸板池 | `getTopicZBPool` | `ztp`涨停价/`zf`振幅/`zs`涨速 |
| 跌停池 | `getTopicDTPool` | `days`连续跌停/`oc`开板次数/`fba`封单 |
| 昨涨停池 | `getYesterdayZTPool` | `ylbc`昨连板/`yfbt`昨首封/`zdp`今日涨幅 |

**通用参数**：`ut=7eea3edcaed734bea9cbfc24409ed989`、`dpt=wz.ztzt`、`date=YYYYMMDD`、`pagesize=10000`

**关键字段单位**：价格 `p/1000`、封板资金/龙虎榜净买=元、新浪成交额=元、腾讯成交额=万元。

## 四、情绪指标计算

| 指标 | 公式 | 含义 |
|---|---|---|
| 炸板率 | 炸板数 / (涨停数+炸板数) | >40% 情绪恶劣 |
| 晋级率 | 昨涨停今日仍涨停数 / 昨涨停数 | >30% 赚钱效应好 |
| 昨涨停溢价 | 昨涨停今日平均涨幅 | >3% 溢价高（接力意愿强） |
| 大面 | 昨涨停今日跌幅>7% 的标的 | 大面多=亏钱效应强 |
| 连板高度 | 最高连板数 | 2板以下=冰点，5板+=高潮 |

### 情绪温度计分级

| 温度 | 特征 | 操作含义 |
|---|---|---|
| 🔥 过热 | 涨停>100 + 晋级率>40% + 最高板≥6 | 高潮，警惕退潮 |
| 🟢 热 | 涨停60-100 + 晋级率30-40% | 可做，容错率高 |
| 🟡 中性 | 涨停30-60 + 晋级率20-30% | 精选个股 |
| ⚪ 冷 | 涨停15-30 + 晋级率<20% | 减仓，等冰点 |
| 🧊 冰点 | 涨停<15 + 最高板≤2 | 冰点转机，关注逆势龙头 |

## 五、关键口径与坑

1. **东财 push2/push2ex 接口有间歇性风控**（`RemoteDisconnected`）——成交额榜/跌幅榜/涨跌家数已用新浪源兜底，勿并发
2. **可转债过滤**：代码 11/12/13 开头从龙虎榜/席位统计剔除
3. **机构专用席位**：`OPERATEDEPT_CODE="0"`；游资席位过滤"自然人/机构投资者"聚合席位
4. **非交易日涨停池空** → 退出并提示
5. **字段单位陷阱**：封板资金/净买=元，价格×1000，腾讯成交额=万元

## 六、与 a-share-market-analysis 的融合

| 本项目 | 融合到已有体系 |
|---|---|
| 市场情绪温度计 | **选股前的宏观约束**——情绪冰点/退潮时，CSI300 扫描降仓 |
| 连板梯队/晋级率 | 判断"打板接力"情绪，补充 XGB 的短线维度 |
| 龙虎榜机构/游资 | 比"主力净流入"更细的聪明钱信号 |
| 板块结构（爆发/扩散/退潮） | ↔ sector_heat 板块热度，题材周期定位 |

**核心增量**：`market_sentiment.py`（市场情绪温度计）。选股 = 个股信号 × 市场情绪——**情绪退潮期，好股也难涨**，这是用户体系缺的"择时"维度。
