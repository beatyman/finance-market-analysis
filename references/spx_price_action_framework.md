# SPX Price Action 算法框架（吸收 SPX-Price-Action-Compass）

> 基于 **Al Brooks + Bob Volman** 经典价格行为理论的全离线确定性量化算法。核心增量价值：**S&R 支撑阻力带一维凝聚聚类** + **严格几何阈值参数**。与缠论（定结构）、pattern_detect.py（已有形态）互补。

---

## 一、核心算法五件套

### 1. Swing 极点检测（前后向滑动窗口）

某根 K 线的 high 大于左右各 N 根的 high → Swing High；low 小于左右各 N 根的 low → Swing Low。

| 用途 | 窗口参数 |
|---|---|
| 默认 S&R | 左5 / 右5 |
| 形态检测 | 左6 / 右6 |
| 短期趋势标签 | 左4 / 右4 |

### 2. 市场结构标签（HH/LH/HL/LL）

- HH：当前波段高 > 前一波段高
- LH：当前波段高 < 前一波段高
- HL：当前波段低 > 前一波段低
- LL：当前波段低 < 前一波段低
- 趋势方向：最近 50 根斜率（>0.3% UP，<-0.3% DOWN，否则 SIDEWAYS）

### 3. S&R 支撑阻力带聚类（核心增量）

**一维凝聚聚类**：把所有 Swing High/Low 价格映射到一维数轴，按 0.12%~0.15% 公差聚类。

- **resistance（阻力）**：仅含 Swing High 触碰的簇
- **support（支撑）**：仅含 Swing Low 触碰的簇
- **flip（互换位）**：同时含 High + Low 触碰的簇（经典支阻互换）
- **强度**：簇内触碰次数，< 2 的过滤（噪声），保留 Top 8 强带

### 4. K线形态（严格几何约束）

| 形态 | 几何判定 |
|---|---|
| Doji | body/range < **8%** |
| 看涨 Pin Bar（锤子） | 下影 > range×**60%**，上影 < **15%**，实体 < **30%** |
| 看跌 Pin Bar（射击之星） | 上影 > range×**60%**，下影 < **15%**，实体 < **30%** |
| Inside Bar | 高低完全包裹在前一根内（突破先兆） |
| Engulfing 吞没 | 实体反向包裹前根 + 范围扩大 |
| Morning/Evening Star | 大K线 + 小星（实体<30% ATR）+ 反向大K线穿透首根一半 |

### 5. 复杂几何形态

| 形态 | 判定参数 |
|---|---|
| 双顶/双底 | 价差 < **0.12%**，时间距离 **8~40** 根 |
| 头肩顶/底 | 头 > 双肩，肩价差 < **0.2%**，肩距 ≥ **6** 根 |
| 对称三角形 | 高点斜率 < -0.01 + 低点斜率 > +0.01 |
| 上升三角形 | 高点斜率 ≈ 0（<0.015）+ 低点斜率 > +0.02 |
| 下降三角形 | 高点斜率 < -0.02 + 低点斜率 ≈ 0（<0.015） |

## 二、关键阈值参数表（Al Brooks/Bob Volman 经典值）

| 参数 | 默认值 | 日线建议 |
|---|---|---|
| Swing 窗口 | 5/5 | 5/5 |
| 聚类公差 | 0.15% | 0.5%（日线波动大） |
| Pin Bar 影线 | 60% | 60% |
| Doji 实体 | <8% | <8% |
| 双顶底价差 | 0.12% | 0.2% |
| 双顶底距离 | 8~40 根 | 8~60 根 |
| 头肩肩价差 | 0.2% | 0.3% |

## 三、富途 S/R 指标（futu_sr_indicator.py）

复刻 TS 版聚类算法的富途牛牛 Python 指标，输出 **R1/R2/R3 + S1/S2/S3** 六条线（离现价最近的排名前三的阻力/支撑）。可直接在富途牛牛自定义指标使用。

## 四、与 a-share-market-analysis 的融合映射

| 本项目概念 | 映射到已有体系 |

| S&R 支撑阻力带 | **新增维度**——配合缠论中枢 + 筹码峰三重共振 |
